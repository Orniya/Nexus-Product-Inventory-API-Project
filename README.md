# Product Inventory API

A simple RESTful API built with Node.js and Express.js for managing products in an inventory.

## Technologies Used

- Node.js
- Express.js
- JavaScript
- Postman

## Features

- Retrieve all products
- Retrieve a product by ID
- Add a new product
- Update an existing product
- Delete a product
- Validate product information
- Handle errors for nonexistent products
